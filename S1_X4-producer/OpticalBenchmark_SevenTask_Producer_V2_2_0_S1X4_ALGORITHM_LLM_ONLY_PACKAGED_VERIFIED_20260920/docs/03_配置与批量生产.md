# 配置与批量生产

配置分两层：

- `public_environment_small_batch.json`：拓扑、槽位、负载状态、请求生成、并发集合等公共环境参数。
- `five_task_small_batch.json`：五任务配置入口，引用 `o_family_small_batch.json` 与 `x2x3_small_batch.json`。

可调参数包括 Case 数、请求数、固定路径 rank、候选 K、任务选择策略、simple-path/action/search-node/complete-solution 等 Oracle 预算。正式大批量生产应复制配置文件后修改，不修改 Python 源码。
