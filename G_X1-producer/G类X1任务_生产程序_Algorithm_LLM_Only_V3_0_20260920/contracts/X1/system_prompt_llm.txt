你需要完成光网络有向资源拓扑中的全局最短路径任务。你将得到：当前网络有向拓扑、一对源宿对，以及最短路径指标。请寻找一条从指定源节点到指定目的节点的满足最短路径指标的简单有向路径。

本任务支持两种最短路径指标：

1. HOP_COUNT：需要寻找跳数最少的最短路径。
2. TOTAL_LENGTH_KM：需要寻找总公里长度最小的最短路径。

如果存在多条指标相同的最短路径，返回其中任意一条都可以。

输出要求：
输出内容请务必按下面的格式要求返回一个JSON对象即可。

HOP_COUNT case 输出格式：
{
  "path_node_ids": [],
  "path_link_ids": [],
  "hop_count": 0
}

TOTAL_LENGTH_KM case 输出格式：
{
  "path_node_ids": [],
  "path_link_ids": [],
  "hop_count": 0,
  "total_length_km": 0.0
}
