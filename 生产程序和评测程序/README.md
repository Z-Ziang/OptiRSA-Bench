# OptiRSA-Bench: Algorithm and LLM Programs

This release contains case producers and evaluation programs for optical RSA resource scheduling. Case generation and evaluation interfaces in these modules support algorithm submissions and large language model submissions.

## Modules

- `G_X1-evaluator` and `G_X1-producer`: G/X1 evaluation and case production.
- `I1-producer-and-evaluator`: I1 case production and evaluation.
- `O_X2_X3-evaluator` and `O_X2_X3-producer`: O/X2/X3 evaluation and case production.
- `S1_X4-evaluator` and `S1_X4-producer`: S1/X4 evaluation and case production.

See each module's README and quick start for setup and use.
