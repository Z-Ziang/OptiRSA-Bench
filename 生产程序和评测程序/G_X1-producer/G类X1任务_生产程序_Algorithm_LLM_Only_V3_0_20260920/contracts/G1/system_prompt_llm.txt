你需要完成光网络无向物理拓扑的图表示理解与转换任务。你将得到：一张连通简单无向光网络拓扑的一种图表示，以及需要转换得到的目标图表示。请你理解当前输入图表示所描述的节点和无向连接关系，并将其准确转换为指定的目标图表示。

本任务涉及三种图表示：
1. 边列表（EDGE_LIST）；
2. 邻接表（ADJACENCY_LIST）；
3. 邻接矩阵（ADJACENCY_MATRIX）。

允许的转换方向包括：
1. 边列表 转换为 邻接表；
2. 边列表 转换为 邻接矩阵；
3. 邻接表 转换为 边列表；
4. 邻接表 转换为 邻接矩阵；
5. 邻接矩阵 转换为 边列表；
6. 邻接矩阵 转换为 邻接表。

图表示规则：
1. 拓扑为无向图，一条无向边连接两个节点；
2. 不允许自环；
3. 不允许重复无向边；
4. 边列表使用二维数组表示，每条无向边写为 [u,v]；[u,v] 仅表示节点 u 与节点 v 相连，不表示 u 指向 v，[u,v] 与 [v,u] 在图语义上等价；
5. 边列表中每条无向边只出现一次。规范化书写时，每条边内部按较小节点编号在前、较大节点编号在后排列，并按边的两个端点编号进行字典序排列；
6. 邻接表使用 JSON 对象表示：键为节点编号的字符串形式，值为该节点全部相邻节点编号组成的数组；
7. 邻接表必须包含全部节点；不得包含自身，不得包含重复邻居；由于拓扑为无向图，邻接关系必须对称；
8. 邻接表规范化书写时，节点键按节点编号升序排列，每个节点的相邻节点数组也按节点编号升序排列；
9. 邻接矩阵的行、列顺序由 case 中给出的节点顺序确定；
10. 邻接矩阵为对称的 0/1 矩阵，主对角线为 0；
11. 转换结果保持原拓扑的节点集合和无向边集合不变。

输出要求：
输出内容请只返回一个 JSON 对象，代表转换后的目标图表示。输出格式请务必按照下方要求输出。

当目标表示为边列表时，输出格式为：
{
  "representation_type": "EDGE_LIST",
  "edge_list": [
    [0,1],
    [0,2]
  ]
}

当目标表示为邻接表时，输出格式为：
{
  "representation_type": "ADJACENCY_LIST",
  "adjacency_list": {
    "0": [1,2],
    "1": [0],
    "2": [0]
  }
}

其中，JSON 对象的键表示节点编号，值表示该节点的全部相邻节点。正式答案按节点编号升序书写各键，并将每个相邻节点数组按升序书写。

当目标表示为邻接矩阵时，输出格式为：
{
  "representation_type": "ADJACENCY_MATRIX",
  "nodes": [0, 1, 2],
  "adjacency_matrix": [
    [0, 1, 1],
    [1, 0, 0],
    [1, 0, 0]
  ]
}

判定规则：输出结果经过规范化后，与标准答案表示同一节点集合和无向边集合，即视为转换正确。顺序、书写方向等差异，不影响正确性。
