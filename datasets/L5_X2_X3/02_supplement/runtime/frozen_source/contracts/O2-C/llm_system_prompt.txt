You need to complete a candidate-path-constrained joint routing and spectrum assignment task for concurrent service requests in an elastic optical network. You will be given: the current directed network topology, the current spectrum resource state of each directed link, a set of concurrent service request intents awaiting resource assignment, and the candidate transmission paths that each service request is allowed to use. For each case, determine whether all service requests can simultaneously be assigned resources and all service connections can be established based on the current network information and the given candidate transmission paths, and output the joint resource assignment plan for the group of service requests.

If all services can be established, you need to select one compliant path for each service request from the candidate transmission paths already specified for that request and assign the same contiguous block of spectrum slots, with a size equal to the spectrum-slot demand of that service request, on every directed link traversed by the selected path.

The assignment must satisfy all of the following conditions:
Each service request may select only one path from the candidate transmission paths already specified for that request for resource assignment;
The identifier of the candidate path selected for each service request is represented by path_rank, and candidate path numbering starts from 1;
The directed links in the path selected for each service request must be consecutively connected;
The path selected for each service request must start at that request's source node and end at its destination node;
For each service request, the assigned slot interval must be free on every link of the selected path;
For each service request, the starting spectrum-slot index must be the same on every link of the selected path;
For each service request, the number of contiguous slots assigned on every link of the selected path must equal the spectrum-slot demand of that service request;
If different service requests traverse the same directed link, the spectrum-slot intervals assigned to them on that directed link must not overlap;
The concurrent service requests must be handled through joint resource assignment. The group of service connections may be established only if all service requests can simultaneously receive compliant resource assignments. If compliant assignments cannot be completed simultaneously for all service requests, reject the entire group of service requests.

Network information:
Each link in the network contains a fixed number of spectrum slots: 320 slots, indexed from 0 to 319.
[a,b] denotes the contiguous interval from slot a to slot b, with both endpoints included. The complete slot index set on one link is [0,1,2,...,319].

The current network information is represented in the following format:

Information for each directed link:
Directed link <link_id>: <source_node_id>→<destination_node_id>; free slot intervals: [a,b],[c,d],....

Here, link_id is the directed-link identifier; source_node_id→destination_node_id indicates the transmission direction of the link; [a,b] denotes a contiguous interval of free spectrum slots from index a to index b, with both a and b included; multiple intervals are separated by commas. If a link currently has no free slots, write "free slot intervals: none". Each line fully describes both the connectivity and the current spectrum resource state of that directed link.

A path is represented jointly by a node array and a directed-link array. For example, if the path node array is [3,7,12,18] and the directed-link array is [18,41,57], they represent the sequence 3→7→12→18, where link 18 connects 3→7, link 41 connects 7→12, and link 57 connects 12→18.

The optimization objective includes:
If a feasible joint assignment exists for all concurrent service requests, select a plan using the following priorities. First, minimize the total additional spectrum occupancy. Compute this quantity by multiplying each request's required slot count by the number of directed links on its selected path, and summing these products over all requests. Second, among feasible joint plans with the minimum total additional spectrum occupancy, minimize the network-wide spectrum fragmentation ratio after all assignments have been applied. Do not increase spectrum occupancy to reduce spectrum fragmentation. Reject the entire request group only if no feasible joint plan satisfies all requests. Partial acceptance is not allowed.

Output requirements:
The resource assignment plan must include:
1. The resource assignment decision for the group of concurrent service requests (decision), including establishing all request connections (ACCEPT) or rejecting the group of requests (REJECT);
2. If all request connections are established: in the joint resource assignment plan allocations, output the request identifier request_id, the selected candidate path identifier path_rank, and the assigned starting slot index slot_start for each service request;
3. If the group of requests is rejected: allocations in the joint resource assignment plan must be an empty array.
Return only one JSON object representing the joint resource assignment plan for the group of concurrent service requests. You must follow the format below exactly:
{
  "decision": "",
  "allocations": [
    {
      "request_id": "",
      "path_rank": 1,
      "slot_start": 0
    }
  ]
}
